# TIL: C++ 역참조 연산자

## 오늘 배운 내용

C++에서 별표(`*`)는 쓰이는 위치에 따라 세 가지 의미로 사용될 수 있다.

1. 곱셈 연산자
2. 포인터 타입 선언 기호
3. 역참조 연산자

이번에는 포인터가 저장한 주소를 따라가서, 그 주소에 있는 값에 접근하는 **역참조 연산자**를 살펴봤다.

![포인터와 역참조 개념도](./assets/C%2B%2B%20Pointer%20Dereferencing%20Explained.png)

## 역참조 연산자란?

포인터에는 다른 변수의 메모리 주소가 저장된다. 포인터 앞에 `*`를 붙이면 포인터가 가리키는 주소에 있는 값에 접근할 수 있다.

```cpp
#include <iostream>
#include <string>

int main()
{
    std::string a = "abcda";
    std::string* b = &a;

    std::cout << "b: " << b << '\n';
    std::cout << "*b: " << *b << '\n';

    return 0;
}
```

<br>

### 출력 예시

```text
b: 0x7ffdf0
*b: abcda
```

`b`에 출력되는 주소는 실행 환경과 실행할 때마다 달라질 수 있다. 중요한 점은 `b`에는 `a`의 주소가 저장되고, `*b`를 사용하면 그 주소에 있는 문자열 `"abcda"`를 읽는다는 것이다.

<br>

## 코드 해석

```cpp
std::string a = "abcda";
```

문자열 변수 `a`를 만들고 `"abcda"`를 저장한다.

```cpp
std::string* b = &a;
```

`b`는 `std::string`형 데이터를 가리키는 포인터다. `&a`는 변수 `a`의 주소를 뜻하므로, `b`에는 `a`의 주소가 저장된다.

```cpp
std::cout << b << '\n';
```

포인터 `b`에 저장된 주소를 출력한다.

```cpp
std::cout << *b << '\n';
```

`*b`로 `b`가 가리키는 주소에 접근해, 그곳에 저장된 문자열 `"abcda"`를 출력한다.

<br>

## `*`의 쓰임 구분하기

```cpp
int result = 3 * 4;          // 곱셈
std::string* b = &a;         // 포인터 타입 선언
std::cout << *b << '\n';     // 포인터 역참조
```

같은 `*` 기호라도 코드에서 사용된 위치에 따라 의미가 달라진다.

<br>

## 오늘 배운 내용 정리

포인터 변수 `b`에는 `a`의 주소가 저장된다. `b`를 그대로 사용하면 저장된 주소를 확인할 수 있고, `*b`를 사용하면 그 주소에 있는 실제 값에 접근할 수 있다. 즉, 역참조 연산자 `*`는 포인터가 가리키는 곳의 값을 읽거나 수정할 때 사용한다.
