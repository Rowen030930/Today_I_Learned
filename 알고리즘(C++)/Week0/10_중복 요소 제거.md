# TIL: `unique()`로 중복 원소 정리하기

## 오늘 배운 내용

`std::unique()`는 범위 안에서 **서로 이웃한 중복 원소**를 정리하는 알고리즘이다.

중복 원소를 만나면 첫 번째 원소만 남기고, 중복되지 않은 원소들을 범위의 앞쪽으로 옮긴다. 정리가 끝난 뒤에는 **새로운 끝 위치를 나타내는 이터레이터**를 반환한다.

`unique()`는 원소를 실제로 삭제해서 컨테이너 크기를 줄이는 함수가 아니다. 반환된 이터레이터와 컨테이너의 `erase()`를 함께 사용해야 크기까지 줄일 수 있다.

<br>

## 연속된 중복만 정리하기

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> values{1, 1, 2, 2, 3, 3, 5, 6, 7, 8, 9};

    auto newEnd = std::unique(values.begin(), values.end());

    for (auto it = values.begin(); it != newEnd; ++it)
    {
        std::cout << *it << " ";
    }

    std::cout << '\n';
}
```

예상 출력:

```text
1 2 3 5 6 7 8 9
```

`unique()`는 이웃한 원소끼리 비교한다. 따라서 같은 값들이 서로 붙어 있으면 중복을 정리할 수 있다.

반면 같은 값 사이에 다른 값이 있으면 한 번에 모두 제거하지 못한다.

```cpp
std::vector<int> values{1, 2, 1};
auto newEnd = std::unique(values.begin(), values.end());
```

이 범위에서는 두 `1`이 서로 이웃하지 않으므로 두 번째 `1`이 중복으로 처리되지 않는다.

<br>


## `erase()`와 함께 사용하기

`unique()`가 반환한 위치부터 컨테이너의 실제 끝까지를 `erase()`로 지우면, 컨테이너 크기도 중복 정리 결과에 맞게 줄어든다.

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> values{1, 1, 2, 2, 3, 3};

    values.erase(
        std::unique(values.begin(), values.end()),
        values.end()
    );

    for (int value : values)
    {
        std::cout << value << " ";
    }

    std::cout << '\n';
}
```

예상 출력:

```text
1 2 3
```

여기서 `unique()`는 중복되지 않은 원소를 앞쪽에 모으고 새로운 끝 위치를 반환한다. 이어서 `erase()`가 새 끝 위치부터 기존 끝까지의 원소를 지운다.

<br>

## 정렬과 함께 사용해 전체 중복 제거하기

입력 전체에서 같은 값들을 중복 없이 남기고 싶다면 먼저 `sort()`로 같은 값들을 이웃하게 만든다.

```cpp
#include <algorithm>
#include <iostream>
#include <vector>

int main()
{
    std::vector<int> values{4, 3, 3, 5, 1, 2, 3};

    std::sort(values.begin(), values.end());

    values.erase(
        std::unique(values.begin(), values.end()),
        values.end()
    );

    for (int value : values)
    {
        std::cout << value << " ";
    }

    std::cout << '\n';
}
```

예상 출력:

```text
1 2 3 4 5
```

`sort()`를 먼저 하면 같은 값들이 서로 이웃하게 된다. 그 다음 `unique()`를 적용하면 전체 범위에서 중복을 정리할 수 있다.

단, 정렬하면 원소의 순서가 바뀐다. 입력 순서를 유지하면서 연속된 중복만 정리하려면 `sort()`를 생략하면 된다.

<br>

## 반환 위치 뒤의 원소

`unique()`는 컨테이너 크기를 바꾸지 않고, 유효한 원소들을 앞쪽에 모은다. 반환된 새 끝 위치 뒤에도 이터레이터는 사용할 수 있지만, 그 구간의 원소 값은 **정해져 있지 않다**.

따라서 뒤쪽 값이 원래 값 그대로 남는다고 생각하거나, 그 값을 결과로 사용하면 안 된다. 컨테이너 크기를 줄일 때는 `erase()`를 함께 사용한다.

<br>

## `map`을 이용한 중복 제거

`std::map`은 키가 중복되지 않도록 관리하는 연관 컨테이너다. 따라서 원소를 키로 넣으면 같은 키는 한 번만 저장된다.

```cpp
#include <iostream>
#include <map>
#include <vector>

int main()
{
    std::vector<int> values{4, 3, 3, 5, 1, 2, 3};
    std::map<int, int> counts;

    for (int value : values)
    {
        ++counts[value];
    }

    for (const auto& [value, count] : counts)
    {
        std::cout << value << " ";
    }

    std::cout << '\n';
}
```

예상 출력:

```text
1 2 3 4 5
```

`map`은 키를 정렬된 순서로 관리하므로, 이 방법은 중복을 제거한 값들을 오름차순으로 확인하기 편하다. 각 값이 몇 번 나왔는지도 `count`에 저장할 수 있다.

<br>

### 입력 순서를 유지하고 싶을 때

`map`에 값을 넣고 다시 순회하면 키 순서로 나온다. 처음 등장한 순서를 유지하려면 값이 처음 삽입된 순간 결과 벡터에 추가하면 된다.

```cpp
#include <iostream>
#include <map>
#include <vector>

int main()
{
    std::vector<int> values{4, 3, 3, 5, 1, 2, 3};
    std::map<int, bool> seen;
    std::vector<int> uniqueValues;

    for (int value : values)
    {
        auto [it, inserted] = seen.emplace(value, true);

        if (inserted)
        {
            uniqueValues.push_back(value);
        }
    }

    for (int value : uniqueValues)
    {
        std::cout << value << " ";
    }

    std::cout << '\n';
}
```

예상 출력:

```text
4 3 5 1 2
```

이 코드는 `map`으로 값이 이미 나온 적 있는지 확인하고, 처음 등장한 값만 `uniqueValues`에 넣는다. `map`의 키는 정렬되어 관리되지만, 결과 출력은 `uniqueValues`에 들어간 순서이므로 입력에서 처음 나타난 순서가 유지된다.

<br>

## `unique()`와 `map` 비교

| 방법 | 중복 판단 기준 | 결과 순서 | 시간 복잡도 |
|---|---|---|---|
| `unique()`만 사용 | 이웃한 원소끼리 비교 | 원래 순서에서 연속 중복 정리 | `O(n)` |
| `sort()` + `unique()` + `erase()` | 전체 값의 중복 정리 | 정렬된 순서 | `O(n log n)` |
| `map`에 키 저장 | 같은 키는 하나만 저장 | 키 기준으로 정렬 | `O(n log k)` |

`n`은 입력 원소 수이고, `k`는 서로 다른 값의 수다. `map`은 트리 기반이므로 원소를 넣거나 찾을 때 보통 `O(log k)`가 걸린다.

`map`은 중복 제거에 사용할 수 있지만, `unique()`와 같은 알고리즘은 아니다. `unique()`는 순차 컨테이너에서 이웃한 원소를 정리하고, `map`은 키의 중복을 허용하지 않는 방식으로 값을 관리한다.

<br>

## 헷갈린 점과 해결 과정

### `unique()`가 벡터에서 원소를 바로 삭제하나요?

아니다. `unique()`는 중복되지 않은 원소를 앞쪽에 모으고 새로운 끝 위치를 반환한다. 벡터 크기를 실제로 줄이려면 `erase()`를 함께 사용해야 한다.

### `unique()`만으로 모든 중복이 제거되나요?

연속된 중복만 제거한다. 전체 중복을 정리하려면 먼저 정렬해서 같은 값을 이웃하게 만든 뒤 `unique()`를 사용한다.

### `map`도 `unique()`와 똑같이 동작하나요?

중복 값을 하나만 남길 수 있다는 점은 비슷하지만 동작은 다르다. `map`은 키를 기준으로 값을 저장하고 정렬한다. `unique()`는 주어진 범위에서 이웃한 원소를 비교한다.

<br>

## 오늘 배운 내용 정리

- `std::unique()`는 이웃한 중복 원소를 정리한다.
- 반환된 이터레이터가 가리키는 위치가 새 끝이다.
- 컨테이너 크기를 줄이려면 `erase(unique(...), end())` 형태로 사용한다.
- 전체 중복을 제거하려면 보통 `sort()` 후 `unique()`를 적용한다.
- `std::map`은 중복 키를 허용하지 않으며, 키 기준으로 정렬된 결과를 제공한다.
- `map`은 `unique()`와 같은 알고리즘이 아니므로 결과 순서와 시간 복잡도를 구분해야 한다.
