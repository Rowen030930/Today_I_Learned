## 오늘 배운 내용

### 재귀함수란?

재귀함수(Recursion)는 함수가 자기 자신을 다시 호출하는 함수다. 함수가 자기 자신을 호출할 때마다 매개변수를 바꾸어 문제를 조금씩 작게 만들고, 작은 문제들의 결과를 이용해 전체 문제를 해결한다.

재귀함수를 만들 때는 다음 두 가지가 필요하다.

- **기저 사례(Base Case)**: 재귀 호출을 멈추는 종료 조건
- **재귀 호출(Recursive Case)**: 문제를 더 작은 형태로 바꾸어 자기 자신을 다시 호출하는 부분

기저 사례가 없거나, 재귀 호출을 해도 종료 조건에 가까워지지 않으면 함수가 끝없이 호출될 수 있다.

<br>

## 팩토리얼

팩토리얼은 1부터 주어진 수까지의 정수를 모두 곱한 값이다. `n`의 팩토리얼은 `n!`로 나타낸다.

예를 들어 다음과 같다.

```text
4! = 4 × 3 × 2 × 1 = 24
```

팩토리얼을 재귀적으로 표현하면 다음과 같다.

```text
n! = n × (n - 1)!
0! = 1
```

`0! = 1`은 재귀 호출을 끝내는 기저 사례가 된다.

<br>

### 재귀함수와 반복문으로 구현한 팩토리얼

```cpp
int fact_rec(int n)
{
    if (n == 0 || n == 1)
    {
        return 1; // 기저 사례
    }

    return n * fact_rec(n - 1); // 재귀 호출
}

int fact_for(int n)
{
    int result = 1;

    for (int i = 1; i <= n; i++)
    {
        result *= i;
    }

    return result;
}
```

위 함수는 `n`이 0 이상의 정수라고 가정한다. 음수가 들어오는 경우를 처리하려면 별도의 입력 검사가 필요하다.

팩토리얼은 반복문으로도 간단히 표현할 수 있다. 반복문은 함수 호출을 계속 쌓지 않지만, 재귀함수는 호출할 때마다 실행 정보가 쌓인다.

| 방식 | 시간 복잡도 | 추가 공간 |
|---|---:|---:|
| 반복문 | `O(n)` | `O(1)` |
| 재귀함수 | `O(n)` | `O(n)` |

따라서 반복문으로 쉽게 해결할 수 있는 문제에서는 반복문이 메모리 사용 면에서 더 효율적일 수 있다. 재귀함수는 문제 자체가 작은 하위 문제들로 나뉘는 구조일 때 표현하기 편하다.

<br>

## 피보나치 수열과 점화식

피보나치 수열은 첫 두 항을 정해두고, 그다음 항부터는 바로 앞의 두 항을 더해 구하는 수열이다. 앞선 항을 이용해 다음 항을 정의하는 식을 **점화식**이라고 한다.

피보나치 수열의 점화식은 다음과 같다.

- 첫 번째 항: `F₀ = 0`
- 두 번째 항: `F₁ = 1`
- 세 번째 항부터: `Fₙ = Fₙ₋₁ + Fₙ₋₂` (`n ≥ 2`)

예를 들어 다음과 같이 계산한다.

```text
F₂ = F₁ + F₀ = 1 + 0 = 1
F₃ = F₂ + F₁ = 1 + 1 = 2
```

수열을 순서대로 나열하면 다음과 같다.

```text
0, 1, 1, 2, 3, 5, 8, 13, ...
```

<br>

### `fibo(4)`의 재귀 호출 과정

`fibo(n)`이 `n`번째 피보나치 수를 반환한다고 하면, `fibo(4)`는 다음처럼 계산된다.

```text
fibo(4)
├── fibo(3)
│   ├── fibo(2)
│   │   ├── fibo(1) = 1
│   │   └── fibo(0) = 0
│   │   → fibo(2) = 1
│   └── fibo(1) = 1
│   → fibo(3) = 2
└── fibo(2)
    ├── fibo(1) = 1
    └── fibo(0) = 0
    → fibo(2) = 1
```

따라서 다음과 같이 계산된다.

```text
fibo(4) = fibo(3) + fibo(2)
        = 2 + 1
        = 3
```

### 피보나치 재귀함수

```cpp
int fibo(int n)
{
    if (n == 0)
    {
        return 0; // 기저 사례
    }

    if (n == 1)
    {
        return 1; // 기저 사례
    }

    return fibo(n - 1) + fibo(n - 2); // 재귀 호출
}
```

`fibo(4)`를 계산하면 같은 `fibo(2)`처럼 동일한 값을 여러 번 계산할 수 있다. 따라서 이 재귀 방식은 `n`이 커질수록 계산량이 빠르게 늘어난다.

## 재귀함수를 사용할 때 주의할 점

### 1. 기저 사례를 반드시 작성한다

기저 사례는 재귀 호출을 멈추는 종료 조건이다. 기저 사례가 없거나, 재귀 호출로 기저 사례에 도달할 수 없으면 함수가 계속 호출될 수 있다.

팩토리얼에서는 `n`이 0 또는 1일 때 1을 반환하도록 종료 조건을 둔다.

```cpp
int fact_rec(int n)
{
    if (n == 0 || n == 1)
    {
        return 1; // 기저 사례
    }

    return n * fact_rec(n - 1); // 재귀 호출
}
```

### 2. 재귀 호출이 종료 조건에 가까워져야 한다

함수끼리 서로 호출하는 구조 자체가 항상 잘못된 것은 아니다. 중요한 점은 호출이 반복되더라도 결국 종료 조건에 도달할 수 있어야 한다는 것이다.

예를 들어 `f(a)`가 `f(b)`를 호출하고 `f(b)`가 다시 `f(a)`를 호출하면서 입력이 바뀌지 않는다면, 기저 사례에 도달하지 못해 무한 재귀가 발생할 수 있다.

```text
f(a) → f(b) → f(a) → f(b) → ...
```

재귀 호출을 할 때는 매개변수가 종료 조건에 가까워지는지 확인해야 한다.

```cpp
// 매개변수가 작아지는 경우
int count_down(int n)
{
    if (n <= 0)
    {
        return 0; // 최솟값에 도달하면 종료
    }

    return count_down(n - 1);
}
```

```cpp
// 매개변수가 커지는 경우
int count_up(int n)
{
    if (n > 5)
    {
        return n; // 정해진 범위를 벗어나면 종료
    }

    return count_up(n + 1);
}
```

## 기저 사례를 재귀 호출보다 먼저 확인하는 이유

재귀함수는 재귀 호출을 하기 전에 기저 사례에 해당하는지 확인해야 한다. 종료 조건에 도달했다면 더 이상 자기 자신을 호출하지 않고 값을 반환해야 하기 때문이다.

기저 사례를 먼저 확인하면 다음과 같은 이점이 있다.

- 종료 조건에 해당할 때 재귀 호출을 막을 수 있다.
- 불필요한 함수 호출을 줄일 수 있다.
- 함수가 언제 끝나는지 코드에서 명확하게 확인할 수 있다.

반대로 종료 조건을 확인하기 전에 재귀 호출부터 하면 종료 조건에 도달해도 호출을 계속할 수 있다. 그러면 무한 재귀가 발생하거나 호출 스택이 가득 차 프로그램이 종료될 수 있다.

<br>

## 헷갈리는 점과 해결 과정

처음에는 재귀함수에서 기저 사례와 재귀 호출 중 무엇이 먼저 실행되어야 하는지 헷갈렸다. 재귀 호출 자체가 문제를 해결하는 핵심처럼 보여서, 먼저 자기 자신을 호출해도 된다고 생각할 수 있었다.

코드의 실행 순서를 따라가 보니, 함수가 자기 자신을 호출하면 현재 함수의 실행은 잠시 멈추고 새 함수 호출로 들어간다. 따라서 종료 조건을 확인하기 전에 재귀 호출을 하면, 종료 조건을 확인할 기회가 뒤로 밀리거나 계속 호출이 이어질 수 있다.

그래서 먼저 기저 사례를 확인하고, 종료 조건이 아닐 때만 재귀 호출을 해야 한다는 점을 이해했다. 또한 함수가 서로 호출하는 것만으로 무한 재귀가 되는 것은 아니며, **호출할 때마다 입력이 종료 조건에 가까워지는지**가 중요하다는 점도 알게 되었다.

## 오늘 배운 내용 정리

재귀함수는 자기 자신을 호출해 큰 문제를 작은 문제들로 나누어 해결하는 함수다. 재귀함수를 작성할 때는 호출을 멈추는 기저 사례를 먼저 확인하고, 재귀 호출을 할 때마다 입력이 종료 조건에 가까워지는지 살펴야 한다. 팩토리얼은 반복문과 재귀함수로 모두 구현할 수 있으며, 피보나치 수열은 점화식에 따라 현재 항을 앞의 두 항의 합으로 구한다.
