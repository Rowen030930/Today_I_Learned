# TIL: 재귀함수와 수학

## 오늘 배운 내용

재귀함수(Recursion)는 함수가 자기 자신을 다시 호출하는 함수다. 매개변수를 바꾸어 같은 일을 반복하며, 큰 문제를 작은 부분 문제로 나누어 풀 때 사용한다.

재귀함수를 만들 때는 재귀 호출을 멈추는 **기저 사례(Base Case)**와 문제를 더 작은 형태로 바꾸는 **재귀 호출(Recursive Case)**이 필요하다.

### 피보나치 점화식

피보나치 수열은 첫 두 항을 정해두고, 그다음 항부터는 **바로 앞의 두 항을 더해** 구하는 수열이다. 이렇게 앞선 항을 이용해 다음 항을 정의하는 식을 **점화식**이라고 한다.

피보나치 점화식은 다음과 같다.

- 첫 번째 항: `F₀ = 0`
- 두 번째 항: `F₁ = 1`
- 세 번째 항부터: `Fₙ = Fₙ₋₁ + Fₙ₋₂` (`n ≥ 2`)

즉, 현재 항은 바로 앞의 두 항을 더해 구한다.

예를 들어 `F₂ = F₁ + F₀ = 1 + 0 = 1`이고,
`F₃ = F₂ + F₁ = 1 + 1 = 2`이다.

```text
0, 1, 1, 2, 3, 5, 8, 13, ...
```

### `fibo(4)`의 재귀 호출 과정

```text
fibo(4)
├── fibo(3)
│   ├── fibo(2)
│   │   ├── fibo(1) = 1
│   │   └── fibo(0) = 0
│   │   → fibo(2) = 1
│   └── fibo(1) = 1
│   → fibo(3) = 2
└── fibo(2)
    ├── fibo(1) = 1
    └── fibo(0) = 0
    → fibo(2) = 1
```

따라서 `fibo(4) = fibo(3) + fibo(2) = 2 + 1 = 3`이다.

## 재귀함수를 사용할 때 주의할 점

### 1. 기저 사례를 반드시 작성한다
<br>

기저 사례(Base Case)는 재귀 호출을 멈추는 종료 조건이다. 기저 사례가 없으면 함수가 계속 자기 자신을 호출할 수 있다.

팩토리얼에서는 `n`이 0 또는 1일 때 1을 반환하도록 종료 조건을 둔다.

```cpp
int fact_rec(int n) {
    if (n == 0 || n == 1) return 1; // 기저 사례
    return n * fact_rec(n - 1);     // 재귀 호출
}

int fact_for(int n) {
    int ret = 1;

    for (int i = 1; i <= n; i++) {
        ret *= i;
    }

    return ret;
}
```
<br>
이 문제는 1부터 `n`까지 차례대로 곱하면 되므로, 반복문으로 간단하게 해결할 수 있다. 반복문은 함수 호출을 반복해서 만들지 않고 추가 메모리도 거의 사용하지 않는다. 반면 재귀함수는 호출할 때마다 함수 실행 정보가 쌓이므로, `n`이 커지면 호출 스택을 더 많이 사용한다.

| 방식     | 시간 복잡도 | 추가 공간 |
|----------|-------------|-----------|
| 반복문   | O(n)        | O(1)      |
| 재귀함수 | O(n)        | O(n)      |

따라서 팩토리얼처럼 반복문으로 쉽게 표현할 수 있는 문제는 보통 반복문을 사용하는 편이 효율적이다. 재귀함수는 문제를 작은 문제로 나누는 구조를 표현하기 좋을 때 사용한다.

### 2. 사이클이 있다면 쓰면 안 된다

`f(a)`가 `f(b)`를 호출하고, `f(b)`가 다시 `f(a)`를 호출하는 것처럼 함수 호출이 서로 반복되는 사이클이 있으면 안 된다. 종료 조건에 도달하지 못해 무한 재귀가 발생할 수 있다.

```text
f(a) → f(b) → f(a) → f(b) → ...
```

## 왜 기저 사례는 맨 앞에 두어야 할까?

재귀함수는 재귀 호출을 하기 전에 기저 사례를 먼저 확인해야 한다. 그래야 종료 조건에 도달했을 때 추가 호출 없이 함수를 끝낼 수 있다.

### 1. 효율성

기저 사례는 재귀함수를 종료시킨다. 기저 사례를 먼저 확인하면 현재 입력에서 재귀 호출이 더 필요한지 바로 판단할 수 있다. 이미 종료 조건에 도달했다면 뒤의 메인 로직을 실행하지 않고 곧바로 반환하므로 불필요한 호출을 줄일 수 있다.

### 2. 무한 재귀 방지

재귀 호출을 기저 사례보다 먼저 실행하면 종료 조건을 확인하기 전에 함수 호출이 계속 이어질 수 있다. 이 경우 기저 사례에 도달하지 못해 무한 재귀가 발생할 수 있다.

### 3. 논리적 흐름

재귀함수는 보통 문제를 더 작은 문제로 나누어 해결한다. 그래서 매개변수가 계속 작아지는 경우에는 최솟값에 도달했을 때 종료해야 한다. 반대로 매개변수가 계속 커지는 경우에도 문제에서 정한 범위를 벗어났는지 확인하고 종료해야 한다.

```cpp
// 매개변수가 작아지는 경우
int count_down(int n) {
    if (n <= 0) return 0;       // 최솟값에 도달하면 종료
    return count_down(n - 1);   // 매개변수를 줄여 재귀 호출
}
```

```cpp
// 매개변수가 커지는 경우
int count_up(int n) {
    if (n > 5) return n;        // 정해진 범위를 벗어나면 종료
    return count_up(n + 1);     // 매개변수를 늘려 재귀 호출
}
```
