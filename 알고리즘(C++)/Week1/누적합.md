# TIL: 누적합으로 구간 합 빠르게 구하기

## 오늘 배운 내용

누적합(Prefix Sum)은 배열의 앞에서부터 각 원소를 차례로 더한 값을 저장한 배열이다.

원본 배열의 구간 합을 매번 처음부터 다시 계산하면, 구간이 길거나 질문이 많을 때 시간이 오래 걸린다. 누적합 배열을 미리 만들어 두면 구간 합을 뺄셈 한 번으로 구할 수 있다.

## 예시 배열로 이해하기

원본 배열이 다음과 같다고 하자.

```text
a = [1, 2, 3, 4]
```

앞에서부터 더한 결과를 누적합 배열에 저장한다.

```text
prefix[0] = 0
prefix[1] = 1
prefix[2] = 1 + 2     = 3
prefix[3] = 1 + 2 + 3 = 6
prefix[4] = 1 + 2 + 3 + 4 = 10
```

결과는 다음과 같다.

```text
a      = [1, 2, 3, 4]
prefix = [0, 1, 3, 6, 10]
```

누적합은 다음 점화식으로 만들 수 있다.

```text
prefix[i] = prefix[i - 1] + a[i]
```

## 구간 합 구하기

배열의 A번째부터 B번째까지의 합은 다음 식으로 구한다.

```text
구간 합 = prefix[B] - prefix[A - 1]
```

예를 들어 배열의 2번째부터 4번째까지 더하면 다음과 같다.

```text
a[2] + a[3] + a[4]
= 2 + 3 + 4
= 9
```

누적합으로 계산하면 다음과 같다.

```text
prefix[4] - prefix[1]
= 10 - 1
= 9
```

`prefix[4]`에는 1번째부터 4번째까지의 합이 들어 있고, `prefix[1]`에는 구하려는 구간보다 앞에 있는 1번째 원소의 합이 들어 있다. 따라서 앞부분의 합을 빼면 2번째부터 4번째까지의 합만 남는다.

## `prefix[0] = 0`으로 시작하는 이유

배열과 누적합을 1번 인덱스부터 사용하면 구간 합 공식이 편해진다.

```text
prefix[i] = prefix[i - 1] + a[i]
```

그리고 A번째부터 더할 때는 다음과 같이 계산한다.

```text
prefix[B] - prefix[A - 1]
```

`prefix[0]`을 0으로 초기화해 두면 A가 1인 구간도 별도 예외 처리 없이 계산할 수 있다.

```text
1번째부터 B번째까지의 합
= prefix[B] - prefix[0]
= prefix[B]
```

## 구간 합 문제의 풀이

카드 N개가 주어지고, A번째부터 B번째까지의 합을 M번 구하는 문제를 생각해 보자.

### 직접 구하는 방법

질문을 받을 때마다 A부터 B까지 반복문을 돌며 더한다.

```cpp
long long sum = 0;

for (int i = A; i <= B; i++)
{
    sum += a[i];
}
```

한 질문에서 최악의 경우 N개를 더할 수 있으므로 질문 M개를 처리하는 시간은 최악의 경우 `O(N × M)`이다.

```text
N = 100,000
M = 100,000

최악의 연산 횟수 ≈ 10,000,000,000
```

질문이 많으면 시간 초과가 발생할 수 있다.

### 누적합을 사용하는 방법

배열을 한 번 읽으면서 누적합을 만들어 둔 다음, 각 질문에 대해 `prefix[B] - prefix[A - 1]`을 계산한다.

```cpp
#include <iostream>
#include <vector>

int main()
{
    std::ios::sync_with_stdio(false);
    std::cin.tie(nullptr);

    int N;
    int M;
    std::cin >> N >> M;

    // 1번 인덱스부터 사용하고, prefix[0]은 0으로 둔다.
    std::vector<long long> prefix(N + 1, 0);

    for (int i = 1; i <= N; i++)
    {
        long long value;
        std::cin >> value;

        // 앞 원소들의 합에 현재 값을 더한다.
        prefix[i] = prefix[i - 1] + value;
    }

    for (int i = 0; i < M; i++)
    {
        int A;
        int B;
        std::cin >> A >> B;

        // A번째부터 B번째까지의 합
        std::cout << prefix[B] - prefix[A - 1] << '\n';
    }

    return 0;
}
```

## 시간 복잡도와 공간 복잡도

| 방법 | 준비 과정 | 질문 하나 처리 | 전체 시간 복잡도 | 추가 공간 |
| --- | --- | --- | --- | --- |
| 매번 직접 더하기 | 없음 | `O(N)` | 최악의 경우 `O(N × M)` | `O(N)` |
| 누적합 사용 | `O(N)` | `O(1)` | `O(N + M)` | `O(N)` |

누적합은 미리 계산하는 데 `O(N)`이 필요하지만, 그 뒤 각 구간 질문은 뺄셈 한 번으로 처리해 `O(1)`이 걸린다.

## 누적합을 떠올릴 때

다음 조건이 보이면 누적합을 고려할 수 있다.

- 배열의 특정 구간 합을 여러 번 물어본다.
- 질문을 처리하는 동안 원본 배열의 값이 바뀌지 않는다.
- 배열을 한 번 순회해 미리 계산해 두는 것이 가능하다.

원본 데이터가 바뀌지 않는 정적 구간 합 문제라면 누적합이 간단하고 빠르다. 값을 자주 수정하면서 구간 합도 계속 구해야 한다면 펜윅 트리나 세그먼트 트리 같은 자료구조를 고려한다.

## 헷갈렸던 점과 해결 과정

- **왜 `prefix[B]`만 사용하면 안 될까?**  
  `prefix[B]`에는 1번째부터 B번째까지의 합이 모두 들어 있다. A보다 앞에 있는 원소들의 합을 빼야 A부터 B까지의 구간 합만 남는다.

- **왜 `prefix[A - 1]`을 빼는가?**  
  `prefix[A - 1]`은 구간 시작점 A보다 앞에 있는 원소들의 합이다. 전체 앞부분 합에서 이 값을 빼면 A부터 B까지의 합이 된다.

- **A가 1이면 인덱스가 0보다 작아지지 않는가?**  
  `prefix[0] = 0`으로 시작하므로 `prefix[1] - prefix[0]`처럼 계산하면 된다.

- **배열을 0번 인덱스부터 써도 되는가?**  
  가능하지만, 이 문제처럼 입력의 A와 B가 1번부터 시작한다면 배열과 누적합을 1번 인덱스부터 사용하는 편이 공식과 코드가 더 직관적이다.

## 오늘 배운 내용 

누적합은 배열의 앞에서부터 더한 결과를 미리 저장해 두는 방법이다. `prefix[i] = prefix[i - 1] + a[i]`로 누적합 배열을 만들고, A번째부터 B번째까지의 합은 `prefix[B] - prefix[A - 1]`로 구한다. 구간 합 질문이 많고 원본 배열이 바뀌지 않는 문제에서 사용하면, 질문 하나를 `O(1)` 시간에 처리할 수 있다.
