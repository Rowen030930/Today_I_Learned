# TIL: 팰린드롬인지 확인하기 — BOJ 10988

<br>

## 문제 이해

팰린드롬은 단어를 앞에서 읽어도, 뒤에서 읽어도 같은 단어다.

예를 들어 `level`은 거꾸로 읽어도 `level`이므로 팰린드롬이다. `baekjoon`은 거꾸로 읽으면 원래 단어와 다르므로 팰린드롬이 아니다.

<br>

## 풀이 방법

원본 문자열을 복사한 뒤, 복사한 문자열을 뒤집는다. 뒤집은 문자열과 원본 문자열이 같으면 `1`, 다르면 `0`을 출력한다.

<br>

## 수정한 코드

```cpp
#include <bits/stdc++.h>
using namespace std;

int main()
{
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    string s;
    cin >> s;

    string reversed = s; // 원본 문자열을 복사한다.
    reverse(reversed.begin(), reversed.end()); // 복사한 문자열을 뒤집는다.

    if (s == reversed)
    {
        cout << 1 << '\n';
    }
    else
    {
        cout << 0 << '\n';
    }

    return 0;
}
```

<br>

## 처음 작성한 코드에서 고친 점

### 1. `reverse()`는 뒤집은 문자열을 반환하지 않는다

처음 작성한 코드:

```cpp
rs = reverse(0, s.size());
```

`reverse()`는 문자열을 반환하는 함수가 아니다. 지정한 범위의 원소 순서를 **직접 바꾸는 함수**다. 따라서 문자열의 시작과 끝을 나타내는 반복자를 전달해야 한다.

```cpp
reverse(reversed.begin(), reversed.end());
```

`begin()`은 문자열의 첫 번째 문자 위치를, `end()`는 마지막 문자 바로 다음 위치를 가리킨다.

### 2. 뒤집기 전에 원본 문자열을 복사한다

원본을 보존하고 뒤집은 결과와 비교하려면, 먼저 문자열을 복사해야 한다.

```cpp
string reversed = s;
```

그다음 복사본만 뒤집으면 원본과 비교할 수 있다.

### 3. 비교 결과를 출력해야 한다

문자열 두 개가 같은지 확인하는 식은 다음과 같다.

```cpp
s == reversed
```

이 결과는 참 또는 거짓이다. 참이면 `1`, 거짓이면 `0`을 출력하도록 `if`문으로 나눴다.

처음 작성한 아래 식은 연산자 우선순위 때문에 의도한 대로 처리되지 않는다.

```cpp
cout << s == rs ? 1 : 0;
```

`cout << s`가 먼저 계산될 수 있어 문자열 비교식으로 사용할 수 없다. 출력 전에 비교하거나, 삼항 연산자를 괄호로 묶어야 한다.

```cpp
cout << (s == reversed ? 1 : 0) << '\n';
```

<br>

## 헷갈렸던 점과 해결 과정

`reverse()`는 새 문자열을 만들어 반환하는 함수가 아니라, 전달된 범위의 순서를 바꾸는 함수다. 그래서 원본 문자열을 유지하려면 복사본을 만든 뒤 그 복사본을 뒤집으면 된다.

<br>

## 시간 복잡도와 공간 복잡도

문자열 길이를 `n`이라고 할 때:

- 시간 복잡도: `O(n)` — 문자열을 한 번 뒤집고 한 번 비교한다.
- 공간 복잡도: `O(n)` — 원본 문자열을 복사한 문자열을 저장한다.

<br>

## 오늘 배운 내용 정리

- 팰린드롬은 뒤집은 문자열과 원본 문자열이 같은 문자열이다.
- `reverse()`에는 뒤집을 범위의 시작 반복자와 끝 반복자를 전달한다.
- `reverse()`는 반환값 대신 전달된 범위를 직접 수정한다.
- 문자열 비교 결과가 참이면 `1`, 거짓이면 `0`을 출력한다.
