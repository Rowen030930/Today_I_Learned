# TIL: 트럭 주차 — BOJ 2979

<br>

## 문제 이해

트럭 세 대가 주차장에 머문 시간이 주어졌을 때, 전체 주차 요금을 계산하는 문제다.

주차 요금은 **트럭 한 대당 1분 요금**으로 주어진다.

| 주차된 트럭 수 | 트럭 한 대당 1분 요금 | 해당 분의 전체 요금 |
|---:|---:|---:|
| 1대 | `A`원 | `A`원 |
| 2대 | `B`원 | `B * 2`원 |
| 3대 | `C`원 | `C * 3`원 |

예를 들어 두 대가 주차된 1분의 요금은 `B`원이 아니라, 두 대의 요금을 합친 `B * 2`원이다.

<br>

## 풀이 방법

각 시간대에 주차된 트럭 수를 배열에 기록한다.

트럭이 도착한 시간이 `start`, 떠난 시간이 `end`라면 다음 범위의 각 분에 주차된 트럭 수를 1씩 증가시킨다.

```text
start <= minute < end
```

도착 시간은 포함하고 떠난 시간은 포함하지 않는다. 예를 들어 `2 5`라면 2분, 3분, 4분 동안 주차한 것이다.

모든 트럭의 주차 시간을 기록한 뒤, 각 분에 주차된 트럭 수에 맞춰 요금을 더한다.

<br>

## 수정한 코드

```cpp
#include <bits/stdc++.h>

using namespace std;

int main()
{
    int A, B, C;
    int parked[101]{}; // 각 분에 주차된 트럭 수
    int totalCost = 0;

    cin >> A >> B >> C;

    for (int i = 0; i < 3; i++)
    {
        pair<int, int> time;
        cin >> time.first >> time.second;

        // 도착 시간은 포함하고, 떠난 시간은 포함하지 않는다.
        for (int minute = time.first; minute < time.second; minute++)
        {
            parked[minute]++;
        }
    }

    // 입력 시간은 1부터 100까지이며, 주차가 가능한 분은 1~99분이다.
    for (int minute = 1; minute < 100; minute++)
    {
        if (parked[minute] == 1)
        {
            totalCost += A;
        }
        else if (parked[minute] == 2)
        {
            totalCost += B * 2;
        }
        else if (parked[minute] == 3)
        {
            totalCost += C * 3;
        }
    }

    cout << totalCost << '\n';

    return 0;
}
```

<br>

## 처음 작성한 코드에서 고친 점

### 1. 배열 초기화

처음 코드의 `int t_arr[101] = 0;`은 배열 전체를 0으로 초기화하는 문법이 아니다.

```cpp
int parked[101]{};
```

중괄호를 사용하면 배열의 모든 원소가 0으로 초기화된다.

### 2. `pair`의 값에 접근하는 방법

`first`와 `second`는 함수가 아니라 멤버 변수다.

```cpp
cin >> time.first >> time.second;
```

따라서 `time.first()`가 아니라 `time.first`처럼 사용해야 한다.

### 3. 현재 분의 트럭 수를 확인하기

배열 전체가 아니라 현재 분의 원소를 확인해야 한다.

```cpp
if (parked[minute] == 1)
```

### 4. 트럭 수에 따라 요금 계산하기

`A`, `B`, `C`는 각각 **트럭 한 대당 요금**이다. 따라서 두 대가 주차된 분에는 `B * 2`, 세 대가 주차된 분에는 `C * 3`을 더해야 한다.

또한 `A`는 한 대, `B`는 두 대, `C`는 세 대가 주차된 경우에 적용된다.

<br>

## 헷갈렸던 점과 해결 과정

시간 배열에는 각 시간대에 주차된 트럭의 **개수**를 저장한다. 트럭이 주차된 분마다 해당 칸을 1씩 증가시키면, 배열을 다시 확인할 때 그 분에 몇 대가 있었는지 알 수 있다.

주차 시간은 도착 시각부터 떠난 시각 전까지이므로 반복문은 다음처럼 작성한다.

```cpp
for (int minute = start; minute < end; minute++)
```

## 오늘 배운 내용 정리

- 시간 배열에 분마다 주차된 트럭 수를 기록한다.
- 도착 시각은 포함하고 떠난 시각은 포함하지 않는다.
- `A`, `B`, `C`는 트럭 한 대당 요금이므로 트럭 수를 곱한다.
- 두 대가 주차된 분은 `B * 2`, 세 대가 주차된 분은 `C * 3`을 더한다.
