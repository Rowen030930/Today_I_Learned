# TIL: 백준 10808번 알파벳 개수

<br>

## 문제 요약

소문자로만 이루어진 단어가 주어진다. 단어에 `a`부터 `z`까지 각 알파벳이 몇 번 등장하는지 세어 순서대로 출력한다.

<br>


## 처음 생각한 풀이

알파벳마다 횟수를 저장할 배열을 만들고, 단어의 문자를 하나씩 확인하려고 했다.

문자에서 `'a'`를 빼면 알파벳 순서에 맞는 배열 인덱스를 얻을 수 있다.

- `'a' - 'a'` → `0`
- `'b' - 'a'` → `1`
- `'z' - 'a'` → `25`

<br>


## 처음 작성한 코드

아래 코드는 처음 작성한 코드를 그대로 옮긴 것이 아니라, **배열로 알파벳 개수를 세려는 의도**가 잘 보이도록 정리한 초안이다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string word;
    int count[25] = {};

    cin >> word;

    for (int i = 0; i < word.size(); i++) {
        count[word[i] - 'a']++;
    }

    for (int i = 0; i < 25; i++) {
        cout << count[i] << ' ';
    }

    return 0;
}
```

<br>


## 처음 코드에서 고칠 점

### 1. 자료형 오타

처음 코드에 작성한 `ing`는 C++ 자료형이 아니다. 횟수를 저장할 정수 배열을 만들려면 `int`를 사용해야 한다.

```cpp
int count[26] = {};
```

### 2. 배열은 26칸이어야 한다

영어 소문자는 `a`부터 `z`까지 총 26개다. 배열 크기가 25이면 `z`의 인덱스인 `25`를 저장할 수 없다.

```cpp
int count[26] = {};
```

### 3. 반복 범위도 26까지 확인해야 한다

출력 반복문이 25칸만 확인하면 마지막 알파벳인 `z`의 개수를 출력하지 못한다.

```cpp
for (int i = 0; i < 26; i++) {
    cout << count[i] << ' ';
}
```

<br>


### 4. 증가 연산 뒤에 세미콜론이 필요하다

처음 코드의 `num_alpha[...]++` 뒤에 세미콜론이 빠져 있었다. C++에서는 문장 끝에 세미콜론을 적어야 한다.

```cpp
count[word[i] - 'a']++;
```

## 수정한 코드

초안의 배열 접근 방식을 유지하면서, 26개의 알파벳을 모두 세고 출력하도록 고쳤다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string word;
    int count[26] = {};

    cin >> word;

    for (int i = 0; i < word.size(); i++) {
        int index = word[i] - 'a';
        count[index]++;
    }

    for (int i = 0; i < 26; i++) {
        cout << count[i];

        if (i < 25) {
            cout << ' ';
        }
    }

    cout << '\n';
    return 0;
}
```

<br>

## 코드 흐름 따라가기

입력 단어가 `banana`라고 가정해 보자.

| 문자 | 계산 | 배열에서 증가하는 칸 |
|---|---|---:|
| `b` | `'b' - 'a'` | 1번 |
| `a` | `'a' - 'a'` | 0번 |
| `n` | `'n' - 'a'` | 13번 |
| `a` | `'a' - 'a'` | 0번 |
| `n` | `'n' - 'a'` | 13번 |
| `a` | `'a' - 'a'` | 0번 |

따라서 `a`의 개수는 3, `b`의 개수는 1, `n`의 개수는 2가 된다. 나머지 알파벳의 개수는 0이다.

<br>

## 시간 복잡도와 공간 복잡도

단어의 길이를 `N`이라고 하면 문자열을 한 번 확인하므로 시간 복잡도는 `O(N)`이다. 알파벳 개수 배열은 항상 26칸을 사용하므로 공간 복잡도는 `O(1)`이다.

<br>

## 오늘의 실수와 배운 점

- 소문자 알파벳 개수는 26개이므로 배열도 26칸이어야 한다.
- `문자 - 'a'`를 이용하면 각 문자를 `0`부터 `25`까지의 배열 인덱스로 바꿀 수 있다.
- 입력 범위와 배열 크기, 반복문 범위가 서로 맞는지 확인해야 한다.
- 지역 정수 배열은 `int count[26] = {};`처럼 초기화해 0부터 세기 시작한다.
