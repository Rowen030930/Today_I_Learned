# TIL: 백준 2309번 일곱 난쟁이

<br>

## 문제 요약

아홉 명의 난쟁이 중 일곱 명을 골라 키의 합이 100이 되는 경우를 찾는다. 정답은 오름차순으로 출력한다.

<br>

## 처음 생각한 풀이

재귀를 이용해 아홉 명 중 일곱 명을 선택하고, 선택한 키의 합이 100인지 확인하려고 했다.

아래 코드는 처음 작성한 코드를 그대로 옮긴 것이 아니라, 내가 의도했던 **조합 탐색 방식**이 잘 드러나도록 변수와 문법을 정리한 초안이다.

<br>

## 처음 생각을 정리한 코드

```cpp
#include <bits/stdc++.h>
using namespace std;

int dwarfHeight[9];
int selected[7];
bool found = false;

void comb(int start, int depth) {
    if (depth == 7) {
        int sum = 0;

        for (int i = 0; i < 7; i++) {
            sum += selected[i];
        }

        if (sum == 100) {
            sort(selected, selected + 7);

            for (int i = 0; i < 7; i++) {
                cout << selected[i] << '\n';
            }

            found = true;
        }

        return;
    }

    for (int i = start; i < 9; i++) {
        selected[depth] = dwarfHeight[i];

        // 현재 선택한 난쟁이를 다시 선택할 수 있는 문제가 있다.
        comb(i, depth + 1);

        if (found) {
            return;
        }
    }
}

int main() {
    for (int i = 0; i < 9; i++) {
        cin >> dwarfHeight[i];
    }

    comb(0, 0);

    return 0;
}
```

<br>

## 처음 코드에서 고칠 점

### 1. 다음 탐색을 시작하는 위치

초안에서는 다음처럼 재귀 함수를 호출했다.

```cpp
comb(i, depth + 1);
```

`i`부터 다시 탐색하기 때문에 방금 선택한 난쟁이를 또 선택할 수 있다. 조합을 만들 때는 이미 선택한 난쟁이 다음 인덱스부터 탐색해야 한다.

```cpp
comb(i + 1, depth + 1);
```

<br>

### 2. 원래 코드의 변수와 배열 사용

처음 코드에서는 `sum`을 선언하지 않은 채 사용했고, 배열 전체에 값을 넣으려 했다.

```cpp
sum += seven_dwarf[i];       // sum 선언 필요
seven_dwarf = dwarf_height[i]; // 배열 전체에 정수 하나를 대입할 수 없음
```

합계 변수는 합을 계산하기 전에 선언하고, 배열에 값을 저장할 때는 인덱스를 지정해야 한다.

```cpp
int sum = 0;
selected[depth] = dwarfHeight[i];
```

<br>

### 3. 재귀 종료 조건

일곱 명을 모두 선택하면 합을 확인한 뒤 현재 재귀 호출을 끝내야 한다. 종료 조건 뒤에서 다시 `depth`를 0으로 바꾸어 재귀 호출하면 탐색이 반복될 수 있다.

```cpp
if (depth == 7) {
    // 합 확인
    return;
}
```

<br>

### 4. 입력 크기와 반복 범위

난쟁이는 아홉 명이므로 입력과 후보 탐색 모두 아홉 명을 대상으로 해야 한다. 반복문의 조건이 `i < 7`이면 마지막 두 명을 확인하지 못한다.

<br>

## 정답 코드에서 배운 점

선생님 코드는 `swap()`으로 배열의 순서를 바꾸어 보고, 배열 앞의 일곱 개 키의 합이 100인지 검사한다. 합이 100인 경우를 찾으면 정렬해 출력한다.

이 방식은 **순열**을 이용한다. 같은 일곱 명을 골라도 순서가 다른 경우를 여러 번 검사할 수 있다.

내가 하려던 방식은 아홉 명 중 일곱 명을 고르는 **조합**이다. 조합 탐색에서는 이미 고른 난쟁이 다음 인덱스부터 확인하면 같은 선택을 순서만 바꾸어 반복할 필요가 없다.

<br>

## 수정한 코드

처음 의도한 조합 탐색을 유지하면서, 다음 탐색을 `i + 1`부터 시작하도록 고쳤다.

```cpp
#include <bits/stdc++.h>
using namespace std;

int dwarfHeight[9];
int selected[7];
bool found = false;

void comb(int start, int depth) {
    if (depth == 7) {
        int sum = 0;

        for (int i = 0; i < 7; i++) {
            sum += selected[i];
        }

        if (sum == 100) {
            sort(selected, selected + 7);

            for (int i = 0; i < 7; i++) {
                cout << selected[i] << '\n';
            }

            found = true;
        }

        return;
    }

    for (int i = start; i < 9; i++) {
        selected[depth] = dwarfHeight[i];

        // 다음 난쟁이는 현재 인덱스 다음부터 선택한다.
        comb(i + 1, depth + 1);

        if (found) {
            return;
        }
    }
}

int main() {
    for (int i = 0; i < 9; i++) {
        cin >> dwarfHeight[i];
    }

    comb(0, 0);

    return 0;
}
```
<br>

## 디버깅 예시

초안처럼 `comb(i, depth + 1)`로 호출하면 같은 난쟁이를 반복해서 선택할 수 있다.

아래 입력에는 키가 `1`인 난쟁이가 한 명뿐이지만, 잘못된 탐색은 그 난쟁이를 여러 번 선택할 수 있다.

```text
1
2
3
4
5
6
7
8
94
```

잘못된 탐색에서는 `1`을 여섯 번, `94`를 한 번 골라 합이 100이라고 판단할 수 있다.

```text
1 + 1 + 1 + 1 + 1 + 1 + 94 = 100
```

하지만 같은 난쟁이를 여러 번 고른 것이므로 올바른 답이 아니다. 재귀 호출을 `comb(i + 1, depth + 1)`로 바꾸면 이미 선택한 난쟁이의 다음 인덱스부터 탐색하므로 중복 선택을 막을 수 있다.

<br>

## 시간 복잡도와 공간 복잡도

아홉 명 중 일곱 명을 고르는 조합의 수는 `C(9, 7) = 36`이다. 각 조합에서 일곱 명의 키 합을 확인한다.

- 시간 복잡도: `O(C(9, 7) × 7)`
- 공간 복잡도: 선택 배열과 재귀 호출을 포함해 `O(7)`

<br>

## 오늘의 실수와 배운 점

- 재귀 함수에는 탐색을 끝내는 종료 조건이 필요하다.
- 배열에 값을 넣을 때는 저장할 위치의 인덱스를 지정해야 한다.
- 조합 탐색에서는 이미 선택한 원소 다음 인덱스부터 탐색해야 중복 선택을 막을 수 있다.
- 재귀 호출이 끝난 뒤 현재 선택을 어떻게 처리할지 생각해야 한다.
- 정답 코드를 그대로 옮기기보다, 풀이 원리를 이해한 뒤 내 방식으로 다시 작성한다.
