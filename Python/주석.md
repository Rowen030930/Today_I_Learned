## 오늘 배운 내용

주석(Comment)은 코드의 동작을 설명하기 위해 작성하는 글이다. 파이썬은 `#` 뒤에 작성한 내용을 주석으로 처리하며, 실행하지 않는다.

```python
# 애완동물 정보를 저장한다.
animal = "고양이"
name = "해피"
age = 4
hobby = "낮잠"

print(animal, name, age, hobby)
```

실행 결과:

```text
고양이 해피 4 낮잠
```

주석은 코드를 읽는 사람이 코드의 목적이나 의도를 이해하는 데 도움을 준다. 코드만 보고도 의미가 분명하다면 주석을 지나치게 많이 달 필요는 없다.

## 한 줄 주석

`#`부터 그 줄의 끝까지가 주석이다.

```python
# 이 줄 전체가 주석이다.
animal = "고양이"  # 변수에 동물 이름을 저장한다.
```

`#` 뒤에 코드를 작성해도 그 부분은 실행되지 않는다.

```python
# print("이 문장은 실행되지 않는다.")
```

## 여러 줄에 주석 쓰기

파이썬에는 C나 C++의 `/* ... */`처럼 여러 줄을 한 번에 주석 처리하는 전용 문법이 없다. 여러 줄을 주석으로 만들 때는 각 줄 앞에 `#`을 붙인다.

```python
# 이 코드는
# 애완동물의 이름과
# 좋아하는 활동을 저장한다.
name = "해피"
hobby = "공놀이"
```

## 따옴표 세 개는 주석이 아니다

강의 화면에서는 다음처럼 따옴표 세 개 안에 여러 줄을 적어 주석처럼 보여 줬다.

```python
'''
이렇게
하면
여러 문장을
주석처럼 적을 수 있다.
'''
```

하지만 `''' ... '''` 또는 `""" ... """`는 파이썬에서 여러 줄 문자열을 만드는 문법이다. 엄밀히 말하면 주석이 아니다. 실제 주석을 작성할 때는 각 줄에 `#`을 사용하는 것이 정확하다.

```python
# 여러 줄의 설명을 적을 때는
# 각 줄 앞에 #을 붙인다.
```

다만 함수나 클래스의 첫 번째 문장 위치에 작성한 문자열은 문서 문자열(Docstring)로 사용된다.

```python
def introduce_pet():
    """애완동물 정보를 소개하는 함수."""
    print("우리집 고양이의 이름은 해피예요")

print(introduce_pet.__doc__)
```

## 오늘 배운 내용 요약

파이썬에서 주석은 `#`으로 작성하며, 주석 내용은 실행되지 않는다. 여러 줄의 주석은 각 줄 앞에 `#`을 붙여 작성한다. 따옴표 세 개는 여러 줄 문자열을 만드는 문법이므로 주석과 구분해서 사용한다.
