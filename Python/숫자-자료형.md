# TIL: 파이썬 숫자 자료형

<br>

## 오늘 배운 내용

오늘은 파이썬의 숫자 자료형을 배웠다. 숫자 자료형에는 정수와 실수가 있다.

- **정수형(`int`)**: 소수점이 없는 숫자다. 양수, 음수, 0을 표현할 수 있다.
- **실수형(`float`)**: 소수점이 있는 숫자다.

숫자 자료형은 `print()`로 화면에 출력할 수 있다.

```python
print(5)
print(-10)
print(3.14)
```

실행 결과:

```text
5
-10
3.14
```

<br>

## Visual Studio Code에서 실행하기

1. Visual Studio Code에서 파이썬 파일을 연다.
2. 파일에 코드를 작성하고 `.py` 확장자로 저장한다.
3. 오른쪽 위의 실행 버튼을 눌러 파이썬 파일을 실행한다.
4. 터미널에 출력된 결과를 확인한다.

<br>

## 헷갈린 점과 해결 과정

정수와 실수의 차이가 헷갈릴 수 있다. 숫자에 소수점이 있는지 확인하면 구분하기 쉽다.

- `5`는 소수점이 없는 정수다.
- `5.0`은 소수점이 있는 실수다.

<br>

## 오늘의 정리

파이썬 숫자 자료형에는 정수형 `int`와 실수형 `float`가 있다. 정수형은 소수점이 없는 숫자이고, 실수형은 소수점이 있는 숫자다. Visual Studio Code에서 `.py` 파일을 실행하고 터미널에서 출력 결과를 확인하는 방법도 익혔다.
