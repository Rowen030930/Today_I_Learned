## 오늘 배운 내용

문자열은 글자나 문장을 표현하는 자료형이다. 파이썬에서는 문자열의 앞뒤를 작은따옴표(`'`)나 큰따옴표(`"`)로 감싸서 작성한다.

```python
print('풍선')
print("나비")
```

작은따옴표와 큰따옴표는 문자열을 감싸는 용도로 모두 사용할 수 있다. 문자열을 출력하면 따옴표 없이 안에 들어 있는 내용이 출력된다.

문자열에는 곱셈 연산자 `*`를 사용할 수도 있다. 문자열에 숫자를 곱하면 해당 문자열이 그 횟수만큼 반복된다.

```python
print("ㅋ" * 9)
```

<br>

## 실습 코드

```python
print('풍선')
print("나비")
print("ㅋㅋㅋㅋㅋㅋ")
print("ㅋ" * 9)
```

<br>

## 헷갈린 점과 해결 과정

- 문자열을 작성할 때는 작은따옴표나 큰따옴표로 내용을 감싸야 한다.
- 작은따옴표와 큰따옴표는 문자열을 표현하는 방법이며, 둘 다 사용할 수 있다.
- `"ㅋ" * 9`는 문자열 `"ㅋ"`을 9번 반복한다는 뜻이다. 숫자 9가 문자열에 더해지는 것은 아니다.

<br>

## 실습 기록
