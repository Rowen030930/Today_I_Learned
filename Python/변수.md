# TIL: 파이썬 변수

<br>

## 오늘 배운 내용

변수는 값을 저장해 두고 프로그램에서 다시 사용할 수 있도록 이름을 붙인 것이다. 파이썬에서는 값을 대입하면 변수에 값이 저장된다.

```python
animal = "고양이"
name = "해피"
age = 4
hobby = "낮잠"
is_adult = age >= 3
```

변수에는 여러 종류의 값을 저장할 수 있다.

| 변수 | 저장한 값 | 자료형 |
|---|---|---|
| `animal` | `"고양이"` | 문자열 |
| `name` | `"해피"` | 문자열 |
| `age` | `4` | 정수 |
| `hobby` | `"낮잠"` | 문자열 |
| `is_adult` | `age >= 3`의 결과 | 불리언 |

<br>

## 변수에 다른 값 대입하기

변수에 새 값을 대입하면 기존 값 대신 새 값이 저장된다.

```python
hobby = "낮잠"
hobby = "공놀이"
```

두 번째 대입 이후 `hobby`에는 `"공놀이"`가 저장된다. 그래서 이후에 `hobby`를 출력하면 `"낮잠"`이 아니라 `"공놀이"`가 나온다.

<br>

## 변수와 출력문 사용하기

```python
print("우리집 " + animal + "의 이름은 " + name + "예요")

hobby = "공놀이"

print(name, "는 ", age, "살이며, ", hobby, "을 아주 좋아해요")
print(name + "는 어른일까요? " + str(is_adult))
```

문자열은 `+`로 연결할 수 있다. 하지만 문자열과 정수처럼 자료형이 다른 값은 그대로 연결할 수 없으므로 `str()`을 사용해 문자열로 바꾼다.

```python
"나이는 " + str(age)
```

`print()`에 값을 쉼표로 구분해 전달하면 여러 값을 출력할 수 있다. 이때 `print()`는 값 사이에 기본적으로 공백을 넣는다. 문자열 안에 공백이 이미 포함되어 있으면 출력할 때 공백이 더 들어갈 수 있다.

<br>

## 비교 결과를 변수에 저장하기

```python
is_adult = age >= 3
```

`age`가 `4`이므로 `age >= 3`의 결과는 `True`다. 이 참·거짓 결과가 `is_adult` 변수에 저장된다.

불리언 값을 문자열에 붙여 출력할 때도 `str()`로 문자열로 바꿀 수 있다.

```python
print(name + "는 어른일까요? " + str(is_adult))
```

<br>

## 실행 결과

```text

해피는 4살이며, 공놀이 을 아주 좋아해요
해피는 어른일까요? True
```

## 헷갈렸던 점과 해결 과정

- **변수에 새 값을 대입하면 기존 값도 남아 있는가?** 아니다. `hobby = "공놀이"`처럼 다시 대입하면 `hobby`의 값이 `"낮잠"`에서 `"공놀이"`로 바뀐다.
- **문자열과 숫자를 `+`로 바로 연결할 수 있는가?** 자료형이 달라 바로 연결할 수 없다. `str(age)`처럼 숫자를 문자열로 바꾼 뒤 연결한다.
- **`age >= 3`의 결과는 어떤 자료형인가?** 비교 연산의 결과는 `True` 또는 `False`인 불리언 값이다. 이번 코드에서는 `4 >= 3`이므로 `True`가 `is_adult`에 저장된다.
- **`print()`의 쉼표와 문자열 연결 `+`는 어떻게 다른가?** `+`는 문자열을 이어 붙이고, 쉼표는 여러 값을 `print()`에 전달한다. 쉼표를 사용하면 출력값 사이에 기본 공백이 들어간다.

<br>

## 오늘 배운 내용 정리

변수는 값을 저장하고 다시 사용하기 위한 이름이다. 변수에 새 값을 대입하면 기존 값이 새 값으로 바뀐다. 문자열과 정수 또는 불리언 값을 `+`로 연결하려면 `str()`을 사용해 문자열로 변환해야 한다. 비교 연산의 결과는 `True`나 `False`로 변수에 저장할 수 있다.
