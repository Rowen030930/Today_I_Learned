## 액션 RPG란?

액션 RPG는 캐릭터를 성장시키는 RPG 요소와 실시간 액션 전투가 결합된 장르다. 플레이어가 캐릭터를 직접 움직이고 공격을 조작하며, 경험치·장비·스킬 등을 통해 캐릭터를 성장시킨다.

## 클론 코드 프로젝트란?

기존 게임이나 프로젝트를 참고해 기능과 동작 방식을 분석하고, 비슷한 기능을 직접 구현해 보는 프로젝트다. 코드를 그대로 복사하는 것보다 각 기능이 어떤 구조로 동작하는지 이해하는 것이 중요하다.

## TIL이란?

TIL은 **Today I Learned**의 약자로, 오늘 새롭게 배운 내용을 꾸준히 기록하는 학습 노트다.

강의 내용을 그대로 옮기기보다 내가 이해한 방식으로 설명하고, 예제나 코드, 아직 헷갈리는 부분을 함께 적는다. 학습 기록을 계속 쌓으면 배운 내용을 복습할 수 있고, 공부해 온 과정도 보여줄 수 있다.

### TIL 작성 순서

1. 날짜와 주제를 제목에 적는다.
2. 오늘 배운 핵심 내용을 내 말로 설명한다.
3. 이해를 돕는 예제나 코드를 기록한다.
4. 아직 헷갈리는 점을 적는다.
5. 다음에 공부하거나 확인할 내용을 적는다.
6. 참고한 강의나 문서가 있다면 출처를 남긴다.

처음부터 완벽하게 쓰려고 하기보다, 배운 내용을 짧게라도 꾸준히 기록하는 것이 중요하다. 공부한 내용은 주제별로 정리하고, 기록이 생기면 GitHub에 반영한다.
