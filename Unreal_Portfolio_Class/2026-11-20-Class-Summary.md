# TIL: 언리얼 C++ 프로젝트 준비와 클린 빌드

## 오늘 배운 내용

Visual Studio Community 2022와 Unreal Engine 5.5.4의 C++ 프로젝트 구성을 확인했다. 프로젝트 폴더를 정리하고 Visual Studio 프로젝트 파일을 다시 생성한 다음 빌드하는 **클린 빌드 과정**도 살펴봤다.

클린 빌드는 기존 빌드 결과물이나 임시 파일을 정리하고 프로젝트를 다시 빌드하는 과정이다. 이전 빌드에서 만들어진 파일 때문에 문제가 생겼을 때 새로 빌드해 확인하는 데 도움이 된다.

## Unreal Engine C++ 프로젝트 준비

Unreal Engine 프로젝트 브라우저에서 C++ 프로젝트 유형과 프로젝트 이름, 위치를 확인했다. 같은 위치에 같은 이름의 프로젝트가 이미 있으면 새 프로젝트를 만들 수 없다는 안내가 표시된다.

![프로젝트 유형과 이름 설정](./assets/프로젝트%20유형과%20이름%20설정.png)

프로젝트 생성 후에는 `Config`, `Content`, `Source` 폴더와 프로젝트 파일을 확인했다.

- `Config`: 프로젝트 설정 파일
- `Content`: 게임 에셋과 맵
- `Source`: C++ 소스 코드
- `.uproject`: 언리얼 프로젝트를 여는 기준 파일
- `.sln`: Visual Studio에서 프로젝트를 작업할 때 사용하는 솔루션 파일

## 클린 빌드 과정

언리얼 프로젝트를 계속 개발하고 빌드하면 빌드 결과물, 임시 파일, 캐시가 만들어진다. 이런 파일을 정리하고 다시 빌드하면 이전에 만들어진 결과물의 영향을 줄인 상태에서 프로젝트를 확인할 수 있다.

오늘 확인한 작업 흐름은 다음과 같다.

1. Unreal Editor와 Visual Studio를 닫는다.
2. 프로젝트에 필요한 폴더와 파일을 확인한다.
3. 빌드 과정에서 생성된 파일과 폴더를 정리한다.
4. `.uproject` 파일을 우클릭하고 **Generate Visual Studio project files**를 선택한다.
5. 생성이 끝나면 프로젝트를 다시 열고 빌드한다.

`Binaries`와 `Intermediate`는 빌드 과정에서 다시 생성되는 파일을 포함한다. `Intermediate`를 삭제하면 Visual Studio 프로젝트 파일도 다시 생성해야 할 수 있다.

`DerivedDataCache`는 에셋을 처리하면서 만들어지는 캐시다. 삭제해도 다시 만들어질 수 있지만, 다음 실행이나 에셋 로딩이 오래 걸릴 수 있다. `Saved`에는 자동 저장 파일과 로그 등이 들어갈 수 있으므로, 정리 전에 필요한 파일이 있는지 확인한다.

오늘은 이미지처럼 프로젝트 폴더를 정리한 뒤 프로젝트 파일 생성 메뉴를 확인했다.

![프로젝트 폴더 정리 후 확인](./assets/프로젝트%20폴더%20정리%20후%20확인.png)

![프로젝트 파일 생성 메뉴 확인](./assets/프로젝트%20파일%20생성%20메뉴%20확인.png)

**Generate Visual Studio project files**는 `.uproject`를 기준으로 Visual Studio 솔루션과 프로젝트 파일을 다시 만드는 기능이다. 이 기능을 실행한 뒤 실제로 다시 빌드해야 클린 빌드 과정이 끝난다.

## Git 설정 파일의 역할

`.gitignore`는 Git이 추적하지 않을 파일과 폴더를 정하는 파일이다. 언리얼 프로젝트에서는 다시 생성할 수 있는 빌드 결과물이나 임시 파일을 저장소에서 제외할 때 사용한다.

`.gitattributes`는 파일 종류에 따라 Git이 파일을 처리하는 방식을 정한다. 텍스트와 바이너리 파일을 구분하거나 줄바꿈, Git LFS 처리 방식을 관리할 때 사용한다.

`.editorconfig`는 여러 편집기와 IDE에서 코드 편집 형식을 일관되게 맞추기 위한 설정 파일이다. 프로젝트 폴더에서 파일이 있는 것은 확인했지만, 내부 설정값은 확인하지 않았다.

<br>

## 헷갈린 점과 해결 과정

프로젝트 파일을 생성하는 것과 빌드하는 것이 같은 단계인지 헷갈렸다. `.uproject`의 **Generate Visual Studio project files** 메뉴는 Visual Studio에서 사용할 솔루션과 프로젝트 정보를 다시 만드는 기능이다. 그 다음 Visual Studio에서 빌드해야 코드가 새로 컴파일된다.

폴더 정리도 무조건 많은 파일을 삭제하면 좋은 것은 아니다. 빌드 결과물과 임시 파일은 다시 생성할 수 있지만, `Saved`에는 자동 저장 파일이나 로그가 있고 `DerivedDataCache`는 삭제 후 다시 만들어질 수 있다. 필요한 파일을 확인한 뒤 정리해야 한다.

<br>

## 오늘 배운 내용 정리

오늘은 Visual Studio의 C++ 게임 개발 구성을 확인하고 Unreal Engine C++ 프로젝트의 폴더 구조를 살펴봤다. 클린 빌드는 빌드 결과물과 임시 파일을 정리하고, `.uproject`에서 Visual Studio 프로젝트 파일을 다시 생성한 뒤 프로젝트를 다시 빌드하는 과정이다.

빌드 파일을 정리하는 것과 소스 코드 내용을 개선하는 것은 서로 다른 작업이다. 폴더를 정리하기 전에는 자동 저장 파일과 로그가 필요한지 확인하고, 캐시를 삭제하면 다음 실행이 오래 걸릴 수 있다는 점도 기억해야 한다.
