## 오늘 배운 내용

### 함수란?

함수는 프로그램에서 특정한 작업을 수행하도록 정의한 독립적인 코드 단위다. 복잡한 문제를 기능별로 나누면 코드를 이해하기 쉬워지고, 같은 코드를 여러 번 작성하지 않고 재사용할 수 있다.

함수는 가능하면 하나의 기능을 맡도록 작성하는 것이 좋다. 각 함수의 역할이 분명해져 코드를 읽고 수정하기 편해진다.
<br><br>

### C 언어에서 사용하는 함수

C 언어에서 사용하는 함수는 크게 **라이브러리 함수**와 **사용자 정의 함수**로 나눌 수 있다.

- **라이브러리 함수**: C 표준 라이브러리나 컴파일러가 제공하는 함수다. `printf`, `scanf`, `rand`, `srand` 등이 있다.
- **사용자 정의 함수**: 라이브러리에서 제공하지 않는 기능을 사용자가 목적에 맞게 직접 작성한 함수다.

라이브러리 함수를 사용하려면 그 함수가 선언된 헤더 파일을 포함해야 한다.

> 표준 라이브러리는 C 언어를 만든 곳이 아니다. C 언어 표준에서 정한 기능과 함수를 제공하는 라이브러리다.

<br><br>

## 난수 발생 함수

난수는 다음에 어떤 값이 나올지 쉽게 예측하기 어려운 임의의 값이다. C 언어에서는 `rand()`로 난수처럼 보이는 값을 얻고, `srand()`로 난수 생성에 사용할 초깃값을 설정한다.

<br><br>

### `rand()` 함수

`rand()`는 설정된 초깃값을 바탕으로 난수처럼 보이는 정수를 반환한다. 하지만 `rand()`만 사용하면 프로그램을 실행할 때마다 같은 순서의 값이 나올 수 있다. 난수 생성기의 초깃값이 실행할 때마다 달라지지 않기 때문이다.

<br><br>

### `srand()` 함수

`srand()`는 `rand()`가 사용할 초깃값(seed)을 설정한다. 강의 예제에서는 현재 시간을 초깃값으로 사용했다.

```c
srand((unsigned int)time(NULL));
```

현재 시간은 프로그램을 실행할 때마다 달라질 수 있으므로, 이를 초깃값으로 사용하면 실행할 때마다 다른 난수 수열을 얻는 데 도움이 된다.

따라서 **실행할 때마다 달라지는 난수 수열을 얻으려면 `srand()`로 초깃값을 설정한 뒤 `rand()`를 사용한다.** `srand()`는 난수 생성기를 초기화하고, `rand()`는 그 생성기에서 값을 가져오는 역할을 한다.

`rand()`와 `srand()`를 함께 사용해도 실제 무작위성을 보장하는 것은 아니다. C의 `rand()`는 의사 난수를 생성하므로, 보안이 필요한 비밀번호나 암호 키 생성에는 적합하지 않다.

<br><br>

## 강의 예제: 1부터 45까지의 숫자 6개 출력하기

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    int count;

    // 현재 시간을 초깃값으로 설정한다.
    // 프로그램을 시작할 때 한 번 호출한다.
    srand((unsigned int)time(NULL));

    printf("1~45 중에서 숫자 6개 출력\n");

    // 1부터 45까지의 숫자를 6번 출력한다.
    for (count = 1; count <= 6; count++)
    {
        printf("%d ", rand() % 45 + 1);
    }

    return 0;
}
```
<br><br>

### 코드 설명

- `#include <stdlib.h>`: `rand()`와 `srand()`를 사용하기 위해 포함한다.
- `#include <time.h>`: `time()`을 사용하기 위해 포함한다.
- `srand((unsigned int)time(NULL))`: 현재 시간을 난수 생성기의 초깃값으로 설정한다.
- `rand() % 45`: `0`부터 `44`까지의 값을 만든다.
- `rand() % 45 + 1`: 결과에 `1`을 더해 `1`부터 `45`까지의 값을 만든다.
- 반복문을 6번 실행해 숫자 6개를 출력한다.

<br><br>

### 실행 결과 예시

강의 화면에서 확인한 실행 결과는 다음과 같았다.

```text
1~45 중에서 숫자 6개 출력
rand() 출력 : 33 9 35 32 33 20
```

다시 실행했을 때는 다음처럼 다른 값이 나올 수 있다.

```text
1~45 중에서 숫자 6개 출력
rand() 출력 : 12 31 39 19 43 17
```

실행할 때마다 출력되는 값은 달라질 수 있다. 실제 출력 결과는 실행 시점과 환경에 따라 달라진다. 또한 현재 시간을 초깃값으로 사용하므로 같은 초 안에 프로그램을 여러 번 실행하면 같은 값이 나올 수도 있다.

<br><br>

## 헷갈리는 점과 해결 과정

처음에는 `rand()`와 `srand()`가 둘 다 난수를 만드는 함수라고 생각했다. 그런데 역할을 나누어 살펴보니 두 함수가 하는 일이 달랐다.

`rand()`는 난수처럼 보이는 값을 반환하고, `srand()`는 `rand()`가 사용할 초깃값을 설정한다. `rand()`만 사용하면 초깃값이 바뀌지 않아 실행할 때마다 같은 난수 수열이 나올 수 있다. 그래서 `srand((unsigned int)time(NULL))`처럼 현재 시간을 초깃값으로 전달하면 실행할 때마다 다른 수열을 얻는 데 도움이 된다.

이 과정을 통해 `srand()`가 난수를 직접 출력하는 함수가 아니라, `rand()`의 난수 수열이 달라지도록 초깃값을 정하는 함수라는 점을 이해했다. 따라서 실행마다 달라지는 난수 수열을 만들려면 프로그램 시작 시 `srand()`를 한 번 호출하고, 필요한 값을 `rand()`로 얻으면 된다.
