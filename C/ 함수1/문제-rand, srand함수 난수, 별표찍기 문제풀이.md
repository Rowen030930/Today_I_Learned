# TIL: `rand()`, `srand()`로 난수 만들기와 별표 찍기

## 오늘 배운 내용

`rand()`와 `srand()`를 사용하면 프로그램에서 난수를 만들 수 있다.

`rand()`는 난수처럼 보이는 정수를 반환한다. 하지만 프로그램을 실행할 때마다 같은 순서의 숫자가 나올 수 있다. 실행할 때마다 다른 결과를 얻으려면 `srand()`로 난수의 시작값인 **시드(seed)**를 설정해야 한다.

`time(NULL)`은 현재 시간을 반환하므로, 이를 시드로 사용하면 프로그램을 실행할 때마다 다른 난수 순서를 만들 수 있다.

```c
srand((unsigned)time(NULL)); // 현재 시간을 시드로 설정
```

시드는 난수를 만들기 전에 한 번 설정한다. 반복문 안에서 `srand()`를 계속 호출하면 안 된다.

## `rand()`의 결과를 원하는 범위로 만들기

`rand()`가 반환하는 값은 범위가 크기 때문에 `%` 연산자로 범위를 줄일 수 있다.

```c
rand() % 10       // 0부터 9까지
1 + (rand() % 10) // 1부터 10까지
```

`rand() % 10`의 결과는 `0`부터 `9`까지다. 여기에 `1`을 더하면 `1`부터 `10`까지의 숫자를 얻을 수 있다.

## 배열에 난수 저장하고 출력하기

첫 번째 문제에서는 크기가 6인 배열에 `1`부터 `10`까지의 난수를 저장한 뒤, 배열의 각 값을 출력한다.

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    int arr[6] = { 0 }; // 난수를 저장할 정수 배열
    int i = 0;          // 반복문에서 사용할 변수

    srand((unsigned)time(NULL)); // 실행할 때마다 다른 난수 순서를 만들도록 시드 설정

    for (i = 0; i < sizeof(arr) / sizeof(arr[0]); i++) {
        arr[i] = 1 + (rand() % 10); // 배열의 각 칸에 1부터 10까지의 난수 저장
    }

    printf("난수가 대입된 것을 출력합니다.\n");

    for (i = 0; i < sizeof(arr) / sizeof(arr[0]); i++) {
        printf("arr[%d] = %d\n", i, arr[i]); // 배열의 인덱스와 저장된 값 출력
    }

    return 0;
}
```

`sizeof(arr)`는 배열 전체의 크기를 바이트 단위로 구한다. `sizeof(arr[0])`은 배열 원소 하나의 크기다. 따라서 두 값을 나누면 배열의 원소 개수를 구할 수 있다.

```c
sizeof(arr) / sizeof(arr[0]) // 배열의 원소 개수
```

## 난수만큼 별표 찍기

두 번째 문제에서는 배열에 난수를 저장하고, 각 난수의 크기만큼 `*`를 출력한다. 바깥쪽 반복문은 배열의 각 원소를 처리하고, 안쪽 반복문은 해당 숫자만큼 별표를 찍는다.

```c
#include <stdio.h>
#include <stdlib.h>
#include <time.h>

int main(void)
{
    int i = 0;       // 배열을 순회할 변수
    int j = 0;       // 별표 출력 횟수를 세는 변수
    int num[10] = { 0 }; // 난수를 저장할 배열

    srand((unsigned)time(NULL)); // 현재 시간을 시드로 설정

    for (i = 0; i < sizeof(num) / sizeof(num[0]); i++) {
        num[i] = 1 + (rand() % 10); // 각 배열 원소에 1부터 10까지의 난수 저장

        printf("num[%d] : ", i); // 현재 배열 인덱스 출력

        for (j = 0; j < num[i]; j++) {
            printf("*"); // 현재 난수의 값만큼 별표 출력
        }

        printf("\n"); // 다음 배열 원소를 새 줄에 출력
    }

    return 0;
}
```

예를 들어 `num[0]`에 `4`가 저장되면 다음처럼 출력된다.

```text
num[0] : ****
```

바깥쪽 `for`문은 배열 원소마다 한 번씩 실행된다. 안쪽 `for`문은 `num[i]`의 값만큼 실행되므로, 배열 원소의 값에 따라 별표 개수가 달라진다.

## 헷갈린 점과 해결 과정

- `rand()`만 사용하면 실행할 때마다 결과가 달라지는 것이 아니라 같은 난수 순서가 반복될 수 있다. `srand()`에서 실행 시점의 시간을 시드로 사용해 이를 바꿀 수 있다.
- `rand() % 10`은 `0`부터 `9`까지의 값이다. 범위를 `1`부터 `10`까지로 바꾸려면 결과에 `1`을 더한다.
- 배열 길이를 직접 숫자로 적는 대신 `sizeof(배열) / sizeof(배열[0])`으로 구할 수 있다.
- 별표 문제에서는 배열 값을 만드는 반복문 안에 별표 출력 반복문을 둔다. 배열 원소 하나를 정한 뒤, 그 값만큼 별표를 출력하기 위해서다.

## 오늘 배운 내용 정리

`rand()`로 난수를 만들고, `srand((unsigned)time(NULL))`로 실행할 때마다 다른 난수 순서를 설정할 수 있다. `%` 연산과 덧셈을 이용하면 원하는 범위의 난수를 만들 수 있다. 배열에 난수를 저장한 뒤 중첩 반복문을 사용하면 각 난수의 크기만큼 별표를 출력할 수 있다.
