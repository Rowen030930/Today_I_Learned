# TIL: C++ 프로그램의 기본 구성 요소

<br>

## 오늘의 학습 목표

오늘은 C++ 프로그램이 어떤 요소로 구성되는지 살펴봤다. 간단한 프로그램을 예로 들어 헤더 파일 포함, `main()` 함수, 코드 블록, 입출력, 문장 끝의 세미콜론이 어떤 역할을 하는지 정리했다.

오늘 배운 내용을 순서대로 정리하면 다음과 같다.

1. `#include`로 필요한 헤더 파일을 포함한다.
2. `main()` 함수에서 프로그램 실행을 시작한다.
3. 중괄호 `{}` 안에 실행할 문장을 작성한다.
4. `cout`과 `cin`을 이용해 화면에 출력하고 입력을 받는다.
5. 문장이 끝나는 곳에 세미콜론을 작성한다.
6. `return 0;`으로 `main()` 함수의 실행을 마친다.

<br>

## 1. C++ 프로그램의 기본 구조

간단한 C++ 프로그램은 다음과 같은 형태로 작성할 수 있다.

```cpp
#include <iostream>

int main()
{
    std::cout << "Hello, C++!" << '\n';
    return 0;
}
```

이 프로그램은 화면에 `Hello, C++!`을 출력한 뒤 종료한다.

<br>

## 2. 기본 구성 요소 살펴보기

### `#include <iostream>`

```cpp
#include <iostream>
```

`#include`는 프로그램에서 사용할 헤더 파일을 포함하라는 전처리 지시문이다. 이 예제에서는 표준 입출력 기능을 사용하기 위해 `iostream`을 포함했다.

`std::cout`과 `std::cin`을 사용하려면 입출력 스트림을 선언한 헤더가 필요하다. `#include` 줄은 전처리 지시문이므로 끝에 세미콜론을 붙이지 않는다.

### `int main()`

```cpp
int main()
{
    // 프로그램의 실행 내용
}
```

`main()`은 프로그램이 실행될 때 시작점이 되는 함수다. 실행 파일을 실행하면 프로그램은 `main()` 함수의 첫 문장부터 진행한다.

`int`는 함수가 정수형 값을 반환한다는 뜻이다. 괄호 `()`는 함수 이름 뒤에 붙으며, 중괄호 `{}` 안에는 함수가 실행할 내용을 작성한다.

### 중괄호 `{}`

```cpp
int main()
{
    std::cout << "Hello, C++!" << '\n';
}
```

중괄호는 함수나 제어문의 코드 범위를 나타낸다. 여는 중괄호 `{`로 코드 블록을 시작하고, 닫는 중괄호 `}`로 끝낸다.

여는 중괄호와 닫는 중괄호가 짝을 이루지 않으면 컴파일 오류가 발생할 수 있다. 코드를 작성할 때 두 괄호가 모두 있는지 확인해야 한다.

### `std::cout`과 `<<`

```cpp
std::cout << "Hello, C++!";
```

`std::cout`은 콘솔 화면으로 내용을 출력하는 표준 출력 스트림이다. `<<`는 출력할 값을 스트림으로 전달할 때 사용한다.

문자열은 큰따옴표로 감싼다.

```cpp
std::cout << "Hello, C++!";
```

문자열뿐 아니라 숫자나 변수도 출력할 수 있다.

```cpp
int score = 100;

std::cout << score;
```

### 줄 바꿈 문자 `'\n'`

```cpp
std::cout << "Hello, C++!" << '\n';
```

`'\n'`은 출력 위치를 다음 줄로 이동시키는 줄 바꿈 문자다. 여러 출력 값을 연달아 연결할 수도 있다.

```cpp
std::cout << "이름: " << "Gyeongrok" << '\n';
std::cout << "점수: " << 100 << '\n';
```

### 세미콜론 `;`

```cpp
std::cout << "Hello, C++!" << '\n';
return 0;
```

세미콜론은 일반적인 C++ 문장이 끝났음을 나타낸다. 세미콜론을 빠뜨리면 문장이 제대로 끝나지 않아 컴파일 오류가 발생할 수 있다.

`#include <iostream>` 같은 전처리 지시문에는 세미콜론을 붙이지 않지만, `std::cout`이나 `return`처럼 C++ 문장으로 작성한 코드는 세미콜론으로 끝낸다.

### `return 0;`

```cpp
return 0;
```

`return`은 함수의 실행을 끝내고 값을 반환한다. `main()`에서 `0`을 반환하는 것은 프로그램이 정상적으로 종료되었다는 의미로 사용한다.

<br>

## 3. `using namespace std;`를 사용하는 형태

강의 예제에서는 표준 라이브러리 이름을 짧게 쓰기 위해 다음처럼 작성할 수도 있다.

```cpp
#include <iostream>

using namespace std;

int main()
{
    cout << "Hello, C++!" << '\n';
    return 0;
}
```

`using namespace std;`를 쓰면 `std::cout` 대신 `cout`처럼 이름을 사용할 수 있다.

두 방식은 아래처럼 대응한다.

| `std`를 붙여 쓰기 | `using namespace std;` 사용 |
|---|---|
| `std::cout` | `cout` |
| `std::cin` | `cin` |
| `std::string` | `string` |

이번 TIL의 기본 예제에서는 이름이 어느 표준 라이브러리에 속하는지 확인하기 쉽도록 `std::cout` 형태를 사용했다.

<br>

## 4. 사용자 입력 받기

`std::cin`은 키보드로 입력한 값을 프로그램에 전달하는 표준 입력 스트림이다. `>>`를 사용해 입력한 값을 변수에 저장할 수 있다.

```cpp
#include <iostream>

int main()
{
    int number = 0;

    std::cout << "숫자를 입력하세요: ";
    std::cin >> number;

    std::cout << "입력한 숫자: " << number << '\n';

    return 0;
}
```

이 코드의 실행 흐름은 다음과 같다.

1. `number`라는 정수형 변수를 만든다.
2. 숫자를 입력하라는 문장을 출력한다.
3. 사용자가 입력한 값을 `number`에 저장한다.
4. 저장된 값을 화면에 출력한다.
5. `return 0;`을 실행하고 프로그램을 종료한다.

<br>

## 5. 주석 작성하기

주석은 코드를 읽는 사람이 내용을 이해하도록 덧붙이는 설명이다. 주석은 프로그램 실행 결과에 영향을 주지 않는다.

한 줄 주석은 `//`로 작성한다.

```cpp
// 사용자에게 인사말을 출력한다.
std::cout << "Hello, C++!" << '\n';
```

여러 줄 주석은 `/*`와 `*/` 사이에 작성한다.

```cpp
/*
이 부분은 여러 줄에 걸친
설명을 작성할 때 사용한다.
*/
```

주석은 코드가 무슨 일을 하는지 설명할 때 사용한다. 이미 코드만 보고도 알 수 있는 내용을 반복하기보다는, 코드의 목적이나 작성 이유를 적는 것이 좋다.

<br>

## 6. 전체 예제와 실행 흐름

```cpp
#include <iostream>

int main()
{
    int number = 0;

    std::cout << "숫자를 입력하세요: ";
    std::cin >> number;

    std::cout << "입력한 숫자: " << number << '\n';

    return 0;
}
```

프로그램의 실행 흐름을 순서대로 표현하면 다음과 같다.

```text
프로그램 실행
    → main() 함수 시작
    → number 변수 생성
    → 안내 문장 출력
    → 숫자 입력
    → 입력한 값 출력
    → return 0으로 main() 종료
```

## 7. 자주 발생하는 작성 실수

### 세미콜론을 빠뜨리는 경우

```cpp
std::cout << "Hello, C++!"
```

문장의 끝에 세미콜론이 빠져 있다. 아래처럼 수정해야 한다.

```cpp
std::cout << "Hello, C++!";
```

### 중괄호의 짝이 맞지 않는 경우

```cpp
int main()
{
    std::cout << "Hello, C++!" << '\n';
```

여는 중괄호 `{`를 썼다면 대응하는 닫는 중괄호 `}`도 작성해야 한다.

```cpp
int main()
{
    std::cout << "Hello, C++!" << '\n';
}
```

### 표준 라이브러리 이름을 찾지 못하는 경우

`using namespace std;`를 쓰지 않았다면 표준 입출력 객체에 `std::`를 붙여야 한다.

```cpp
std::cout << "Hello, C++!" << '\n';
```

또는 파일 위쪽에 `using namespace std;`를 작성하고 `cout`처럼 사용할 수 있다.

<br>

## 헷갈렸던 점과 해결 과정

- **`#include` 뒤에는 왜 세미콜론이 없는가?** `#include`는 C++ 문장이 아니라 전처리 지시문이다. 따라서 `#include <iostream>` 뒤에는 세미콜론을 쓰지 않는다.
- **`main()`은 왜 필요한가?** 프로그램이 실행될 때 어디서부터 시작할지 나타내는 함수이기 때문이다. 실행 흐름은 `main()`의 첫 문장에서 시작한다.
- **`std::cout`과 `cout`은 다른 기능인가?** `using namespace std;`를 사용했는지에 따라 표기 방식이 달라진다. `std::cout`은 표준 라이브러리의 출력 객체를 명확히 가리키고, `using namespace std;`를 사용하면 `cout`으로 줄여 쓸 수 있다.
- **중괄호와 세미콜론은 같은 역할을 하는가?** 중괄호는 코드 블록의 범위를 나타내고, 세미콜론은 일반적인 문장이 끝났음을 나타낸다. 역할이 다르므로 각각 필요한 위치에 작성해야 한다.
- **`return 0;`은 화면에 0을 출력하는 코드인가?** 아니다. `return 0;`은 `main()` 함수가 정수값 0을 반환하고 종료한다는 뜻이다. 화면에 값을 출력하려면 `std::cout`을 사용한다.

<br>

## 오늘 배운 내용 

C++ 프로그램은 `main()` 함수에서 실행을 시작한다. `#include <iostream>`으로 표준 입출력 헤더를 포함하고, `std::cout`으로 화면에 출력하거나 `std::cin`으로 값을 입력받을 수 있다. 함수와 코드 블록은 중괄호로 범위를 나타내며, 일반적인 C++ 문장의 끝에는 세미콜론을 붙인다. `return 0;`은 `main()` 함수를 종료하고 정상 종료를 알리는 데 사용한다.
