# TIL: 변수와 메모리

<br>

## 오늘 배운 내용

변수는 프로그램이 값을 저장하고 다시 사용할 수 있게 해 주는 이름이다. 변수에 값을 저장하면 메모리에 그 값을 보관할 공간이 마련되고, 프로그램은 변수 이름을 사용해 해당 값을 읽거나 바꾼다.

아래처럼 `int a = 10;`을 실행하면 `a`라는 정수형 변수를 정의하고, 처음 값을 `10`으로 초기화한다.

```cpp
#include <iostream>

int main()
{
    int a = 10; // 정수형 변수 a를 정의하고 10으로 초기화한다.

    a = 20; // 이미 만들어진 a에 새 값을 대입한다.

    std::cout << a << '\n'; // a에 저장된 값을 읽어 출력한다.
    std::cout << static_cast<const void*>(&a) << '\n'; // a의 메모리 주소를 출력한다.

    return 0;
}
```

`a`의 주소는 실행할 때마다 달라질 수 있다. 주소를 고정된 값으로 외우기보다, 변수가 메모리의 한 위치에 저장된다는 점을 이해하는 것이 중요하다.

## 변수 정의, 초기화, 대입, 사용

| 구분 | 예시 | 의미 |
| --- | --- | --- |
| 정의 | `int a;` | `a`라는 정수형 변수를 만든다. |
| 초기화 | `int a = 10;` | 변수를 만들면서 처음 값을 저장한다. |
| 대입 | `a = 20;` | 이미 만들어진 변수에 새 값을 저장한다. |
| 읽기 | `std::cout << a;` | 변수에 저장된 값을 읽어 출력한다. |

초기화와 대입은 모두 값을 저장하지만 시점이 다르다.

```cpp
int a = 10; // 정의와 초기화를 함께 한다.
a = 20;     // 이후에 새로운 값을 대입한다.
```

지역 변수는 초기값을 지정하지 않으면 값이 정해져 있지 않을 수 있다. 값을 넣기 전에 읽지 않도록 초기화하는 습관을 들인다.

```cpp
int score = 0; // 사용할 초기값을 지정한다.
```

## 자료형과 메모리

자료형은 변수에 어떤 종류의 값을 저장할지 정한다. 또한 프로그램이 그 값을 어떤 방식으로 해석할지도 알려준다.

```cpp
char letter = 'A';
short smallNumber = 12;
int number = 12;
```

강의에서 확인한 환경에서는 `int`가 4바이트였지만, 자료형의 실제 크기는 플랫폼과 구현에 따라 달라질 수 있다. C++에서는 `sizeof`로 확인할 수 있다.

```cpp
#include <iostream>

int main()
{
    std::cout << "char: " << sizeof(char) << " byte\n";
    std::cout << "short: " << sizeof(short) << " bytes\n";
    std::cout << "int: " << sizeof(int) << " bytes\n";

    return 0;
}
```

메모리 창에는 값의 이름이 아니라 메모리에 저장된 바이트와 주소가 보인다. 같은 바이트라도 자료형에 따라 정수, 문자, 실수 등으로 다르게 해석할 수 있다.

## 디버거의 메모리 창으로 확인하기

강의에서는 중단점과 메모리 창을 이용해 변수의 주소와 저장된 값을 살펴봤다.

1. 변수에 값을 대입한 뒤 실행을 멈출 위치에 중단점을 설정한다.
2. 디버깅을 시작하고 메모리 창을 연다.
3. 변수의 주소 표현인 `&a`를 메모리 창의 주소 입력란에 넣는다.
4. 해당 주소 주변의 메모리 값을 확인한다.

`&a`에서 `&`는 변수 `a`의 주소를 구하는 주소 연산자다. 주소는 실행 환경이나 실행 시점에 따라 달라질 수 있다.

## 헷갈렸던 점과 해결 과정

- **변수 이름이 곧 메모리 주소인가?**  
  입문 단계에서는 변수 이름이 메모리 위치에 붙인 이름이라고 생각하면 이해하기 쉽다. 정확히는 변수를 통해 그 변수가 나타내는 객체의 저장 공간과 값에 접근한다.

- **`int a;`만 써도 값이 0이 되는가?**  
  아니다. 지역 변수는 초기화하지 않으면 값이 정해져 있지 않을 수 있다. 사용하기 전에 초기값을 지정한다.

- **초기화와 대입은 어떻게 다른가?**  
  초기화는 변수를 만들 때 처음 값을 정하는 것이고, 대입은 이미 만들어진 변수에 값을 저장하거나 바꾸는 것이다.

- **변수에 값을 출력하면 무슨 일이 일어나는가?**  
  프로그램은 변수에 연결된 메모리 위치에서 값을 읽어 출력한다. `a = 20;`은 그 위치에 새 값을 쓰는 동작이다.

- **모든 컴퓨터에서 `int`는 4바이트인가?**  
  강의의 실행 환경에서는 4바이트였지만, 모든 환경에서 항상 그렇다고 가정하지 않는다. `sizeof(int)`로 확인한다.

## 오늘 배운 내용 요약

변수는 값을 저장하고 읽고 바꾸기 위한 이름이다. 변수를 정의하면 자료형에 맞는 저장 공간이 마련되고, 초기화는 변수를 만들면서 첫 값을 지정하는 동작이다. 이후의 대입은 변수에 새 값을 쓰며, 변수 사용은 그 값을 읽거나 변경하는 일을 뜻한다. 디버거의 메모리 창을 이용하면 변수의 주소와 실제 저장 내용을 확인할 수 있다.
