# TIL: 비트, 바이트, 16진수와 메모리

<br>

## 오늘 배운 내용

컴퓨터는 데이터를 내부적으로 `0`과 `1`의 조합으로 저장한다. 사람이 메모리 값을 읽기 쉽게 확인할 때는 2진수 대신 16진수 표기를 자주 사용한다.

메모리는 값을 저장하는 공간이고, 각 공간에는 위치를 나타내는 주소가 있다. 변수는 이런 메모리 공간을 코드에서 편하게 다루기 위해 붙이는 이름이다.

---
<br>

## 1. 비트와 바이트

### 비트(Bit)

비트는 컴퓨터가 다루는 가장 작은 데이터 단위다. 하나의 비트는 `0` 또는 `1`을 나타낸다.

```text
1비트: 0 또는 1
```

### 바이트(Byte)

일반적으로 1바이트는 8비트로 이루어진다.

```text
1바이트 = 8비트
```

예를 들어 다음은 1바이트를 나타내는 8개의 비트다.

```text
10101011
```

비트가 많아지면 2진수로 값을 읽고 쓰기가 길고 번거로워진다. 그래서 메모리 값을 확인할 때는 16진수 표기를 자주 이용한다.

<br>

## 2. 16진수

16진수는 0부터 15까지의 값을 한 자리로 표현한다. 0부터 9까지는 숫자를 쓰고, 10부터 15까지는 알파벳 `A`부터 `F`까지 사용한다.

| 10진수 값 | 16진수 표기 |
|---:|:---:|
| 10 | A |
| 11 | B |
| 12 | C |
| 13 | D |
| 14 | E |
| 15 | F |

C++ 코드에서 16진수 정수는 보통 앞에 `0x`를 붙여 쓴다.

```cpp
int value = 0xAB;
```

`0xAB`는 다음과 같이 계산한다.

```text
A = 10
B = 11

0xAB
= 10 × 16¹ + 11 × 16⁰
= 160 + 11
= 171
```

따라서 `0xAB`는 10진수로 `171`이다.

<br>

## 3. 2진수와 16진수의 관계

16진수 한 자리는 2진수 네 자리로 바꿀 수 있다. 4비트로 만들 수 있는 조합은 16개이기 때문이다.

```text
A = 10진수 10 = 2진수 1010
B = 10진수 11 = 2진수 1011
```

따라서 다음과 같이 바꿀 수 있다.

```text
0xAB = 1010 1011₂
```

한 바이트는 8비트이므로, 16진수 두 자리가 한 바이트의 값을 표현한다.

```text
1010 1011₂ = AB₁₆
```

16진수는 실제 메모리에 저장되는 방식 자체가 아니다. 값은 컴퓨터 내부에서 0과 1로 저장되며, 16진수는 그 값을 사람이 보기 편하게 나타내는 표기법이다.

<br>

## 4. 메모리와 주소

메모리는 프로그램이 사용하는 데이터를 저장하는 공간이다. 메모리의 각 바이트에는 위치를 나타내는 번호가 붙어 있는데, 이 번호를 **주소(Address)**라고 한다.

메모리를 칸이 나뉜 큰 보관함이라고 생각할 수 있다.

```text
주소       메모리 값
0x1000     ...
0x1001     ...
0x1002     ...
```

주소도 숫자이므로 10진수로 표현할 수 있지만, 메모리를 확인할 때는 16진수 표기를 자주 사용한다.

메모리의 값은 실제로 0과 1의 조합으로 저장된다. 디버거에서는 이 값을 16진수로 확인할 수 있어, 긴 2진수보다 읽기 쉽다.

## 5. 변수와 메모리 공간

변수는 메모리 공간에 붙이는 이름이다. 변수를 정의하면 자료형에 맞는 크기의 메모리 공간이 마련되고, 변수에 값을 대입하면 그 공간에 값이 저장된다.

```cpp
int score = 10;
```

이 코드는 `score`라는 이름으로 정수형 데이터를 다룰 공간을 만들고, 그 공간에 `10`을 저장한다.

```text
변수 이름: score
저장된 값: 10
메모리 주소: 프로그램 실행 중 정해지는 위치
```

변수 이름을 사용하면 메모리 주소를 직접 기억하지 않아도 값을 읽고 쓸 수 있다.

```cpp
score = 20;                  // 변수 공간에 새 값을 저장
std::cout << score << '\n';  // 변수 공간의 값을 읽음
```

메모리 주소와 변수에 저장된 값은 서로 다른 정보다.

- **주소**: 값이 저장된 위치
- **값**: 그 위치에 저장된 데이터
- **변수 이름**: 코드에서 그 메모리 공간을 부르는 이름

## 6. 코드로 값과 주소 확인하기

아래 코드는 변수의 값과 메모리 주소를 출력하는 예시다.

```cpp
#include <iostream>

int main()
{
    int number = 171;

    std::cout << "값: " << number << '\n';
    std::cout << "주소: " << static_cast<const void*>(&number) << '\n';

    return 0;
}
```

주소는 프로그램을 실행할 때마다 달라질 수 있다. 중요한 점은 주소를 특정 값으로 외우는 것이 아니라, 변수가 메모리의 한 위치를 가리킨다는 관계를 이해하는 것이다.

## 헷갈린 점과 해결 과정

- **16진수로 저장되는 건가?**  
  아니다. 데이터는 컴퓨터 내부에서 0과 1로 저장된다. 16진수는 메모리의 값을 사람이 보기 편하게 표현하는 방법이다.

- **비트와 바이트는 어떻게 다른가?**  
  비트는 0 또는 1 하나를 표현하는 단위이고, 바이트는 일반적으로 8비트가 모인 단위다.

- **주소와 값은 같은가?**  
  다르다. 주소는 데이터가 있는 위치이고, 값은 그 위치에 저장된 데이터다.

- **변수는 메모리 그 자체인가?**  
  변수는 메모리 공간을 코드에서 쉽게 사용하도록 붙인 이름이다.

- 16진수 한 자리는 4비트로 나타낼 수 있고, 두 자리는 한 바이트를 표현한다.

- 메모리의 각 바이트에는 주소가 있다.
- 변수는 메모리 공간에 붙인 이름이며, 주소·값·이름은 서로 구분해야 한다.
