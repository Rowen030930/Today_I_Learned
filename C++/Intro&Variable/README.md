# 참고 강의

- **강의명:** 전북대학교 컴퓨터공학부 C++ 프로그래밍
- **강의자:** 김형기
- **출처:** [YouTube 강의 영상](https://www.youtube.com/watch?v=wcvSwA2MBqw)
- **강의 소개:** C++ 프로그래밍의 기초 개념을 다루는 강의 시리즈입니다. 프로그램의 컴파일과 링킹 과정부터 변수, 메모리와 같은 프로그래밍의 기본 원리를 설명합니다. 관련 개념을 실제 코드와 함께 살펴보며 C++ 프로그램이 어떻게 작성되고 실행되는지 이해하는 데 도움을 줍니다.
- **참고 교재:** 윤성우, 『윤성우의 열혈 C++ 프로그래밍』
